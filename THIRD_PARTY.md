# Dependências

A licença MIT cobre o código deste projeto. As bibliotecas mantêm suas próprias licenças:

- PySide6 / Qt: licenças LGPL/GPL/comercial conforme os módulos e a distribuição. Consulte <https://doc.qt.io/qtforpython-6/licenses.html> e os avisos do pacote instalado.
- psutil: BSD-3-Clause, <https://github.com/giampaolo/psutil>.
- comtypes: MIT, <https://github.com/enthought/comtypes>.
- tzdata: Apache-2.0 para o pacote; dados IANA conforme seus avisos, <https://pypi.org/project/tzdata/>.
- PyInstaller, usado só no build: GPL com exceção para distribuição de aplicativos, <https://pyinstaller.org/en/stable/license.html>.

Serviços externos seguem seus próprios termos, cotas, planos e requisitos de atribuição. O aplicativo identifica as fontes em Widgets e fontes. Open-Meteo e Frankfurter oferecem dados com frequências diferentes de atualização. A distribuição de um binário deve preservar os avisos e obrigações das dependências aplicáveis; este pacote não inclui uma revisão de licenciamento para comercialização.
